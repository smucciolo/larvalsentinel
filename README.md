This repository contains data files (.csv) and an R script for our manuscript titled "The impact of milkweed species on monarch survival and predation in a backyard garden". All data is formatted to be used for Kaplan-Meier analyses. 

Data for larval experiment can be found in: 2023 sentinel data_kaplan meier.csv
Data for egg experiment can be found in: eggkaplan_withcontrol_9.24.2024.csv
